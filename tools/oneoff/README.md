# One-off scripts

Script chỉ dùng một lần để sửa dữ liệu cụ thể. Không đưa vào pipeline.

| Script | Ghi chú |
|---|---|
| `fix_factcheck.py` | Đã áp dụng cho project `ai-nho-tren-may`; sửa lại năm của MobileBERT/DistilBERT trong `projects/.../scripts/` |
| `make_demo_media.py` | Tạo audio im lặng + word timing cho demo visual, tránh phải chạy TTS khi chỉ kiểm tra style |

Nếu script đã chạy xong và không còn giá trị tái sử dụng, xoá để repo gọn.
